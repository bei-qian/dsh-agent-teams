# Abuse case 示例集（STRIDE，防御性验证）

> 注入防火墙：本文当**数据**、自写零逐字。示例用于演示「威胁 → 防御 → 可断言测试」的闭环，不是攻击教程。

## 示例 A：登录端点（认证 / 信息泄露 / 提权）

组件：`/login`　信任边界：互联网 → 认证服务

| 类 | abuse case（防御问法） | 防御 | 可断言测试 |
|---|---|---|---|
| S | 用盗来的会话/伪造 token 冒充用户 | 强认证 + 签名会话 + 超时 | 伪造/过期 token → 401，与无 token 响应一致 |
| I | 通过「用户不存在」vs「密码错」的错误差异枚举账号 | 泛化错误 + 恒定路径 | 两分支**状态码/响应体/KDF 调用计数**一致（见 `scripts/security_invariants_demo.mjs`） |
| D | 暴力尝试拖垮登录 | 锁定 + 限流 + 上限 | 超阈尝试 → 429/锁定，计数断言 |
| E | 登录后越权访问他人资源 | 每请求对象级授权 | 用户 A token 读 B 的资源 → 403/404 且不泄露存在性 |

## 示例 B：多租户列表接口（提权 / 信息泄露）

组件：`GET /items`　信任边界：租户 → 服务

| 类 | abuse case | 防御 | 可断言测试 |
|---|---|---|---|
| E | 篡改 `tenant_id`/`item_id` 越权读 | 以会话租户为准，忽略/校验入参租户 | A 请求带 B 的 id → 空集/403，不返回 B 数据 |
| I | 列表回显超出权限的字段 | 字段级授权/脱敏 | 响应字段集合 = 允许集合 |
| T | 批量接口篡改归属写他人数据 | 服务端强制归属 | 写到非本人 → 拒绝且原数据不变 |

## 示例 C：文件上传（篡改 / DoS / 提权）

组件：上传端点　信任边界：用户文件 → 存储

| 类 | abuse case | 防御 | 可断言测试 |
|---|---|---|---|
| T | 上传可执行/脚本伪装成图片 | 类型白名单 + magic 校验 + 存为不可执行 | 伪造扩展名 → 拒绝 |
| D | 超大文件耗尽存储/内存 | 大小上限 + 流式处理 | size=上限+1 → 413，且已用内存有界 |
| E | 路径穿越写库外文件 | 规范化路径 + 基底目录约束 | `../` 路径 → 拒绝 |

## 示例 D：服务间 / Webhook（伪装 / 篡改 / 抵赖）

组件：入站 webhook　信任边界：第三方 → 服务

| 类 | abuse case | 防御 | 可断言测试 |
|---|---|---|---|
| S | 伪造来源调用 webhook | 共享密钥 HMAC 校验 + 时间窗 | 签名错/过期 → 拒绝 |
| T | 重放旧请求 | nonce/时间戳 + 幂等 | 重放 → 拒绝/无副作用 |
| R | 否认发过某事件 | 审计日志不可篡改 | 关键事件必留审计记录 |

## 使用约定

- 每条 abuse case 必须绑定：**防御机制 + 可断言测试（或「人工判断」+ 理由）**。
- 无测试的 abuse case 进残余风险表，评审时按「有威胁无测试」标 blocker/major。
- 测试命名点明威胁类（如 `info-disclosure: login responses indistinguishable`）。
